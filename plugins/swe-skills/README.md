# SWE Skills

SWE Skills is the companion plugin for Superpowers' software-engineering guidance.

It provides:

- `behavior-guidelines`
- `code-review`
- `design-an-interface`
- `managing-skill-library`
- `self-evolved`

Install `superpowers` for the core workflow skills and session bootstrap, then install `swe-skills` for these companion skills. Installing `swe-skills` alone exposes its five skills without injecting Superpowers bootstrap context.
