# design-taste-frontend

Persistent frontend design reference for this repository.

Canonical upstream source:
https://github.com/Leonxlnx/taste-skill/tree/main/skills/taste-skill

Use the upstream `SKILL.md` and its app-screen/page-specific references as the source of truth. For dashboard/admin applications, use the app-screen route and avoid generic AI UI patterns such as excessive gradients, tinted icon squares, decorative cards, and invented vanity metrics.
