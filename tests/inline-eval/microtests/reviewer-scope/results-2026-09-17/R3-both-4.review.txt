2. **Reading files silently removes characters**
   - **File:** `wordstat/cli.py:15`
   - Default universal-newline translation converts CRLF to LF before counting. Input `a\r\nb\r\n` contains six characters, but the report says `chars: 4`.
   - This violates the character-count requirement, including whitespace, for ordinary Windows text files.
   - Open with `newline=""` to preserve characters and add a CRLF integration test.

3. **Undecodable input escapes error handling**
   - **File:** `wordstat/cli.py:16–17`
   - A non-UTF-8 file raises `UnicodeDecodeError`, which the `OSError` handler does not catch.
   - Users encounter an uncaught exception instead of a concise diagnostic and controlled failure.
   - Catch `UnicodeError` alongside `OSError`, return 1, and test invalid UTF-8. Document the accepted encoding.
